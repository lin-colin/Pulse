内存压力应该怎样显示？

活动监视器表达的是“压力状态”，不是一个公开的官方百分比。请优先看哪种表达最真实、最容易一眼读懂。

ϟ 31.5 W ▣ 正常 ♨ 34.0 °C ▦ 64%

A · 官方状态优先（推荐）

内存显示“正常 / 警告 / 严重”，颜色直接对应 macOS 的绿 / 黄 / 红压力状态。最接近活动监视器，不制造并不存在的官方百分比。

ϟ 31.5 W ▣ 低 22 ♨ 34.0 °C ▦ 64%

B · 状态 + 平滑分数

同时显示压力等级和 0–100 的自定义趋势分数。颜色变化更细腻，但这个数字只能称为“Pulse 压力分数”，不能冒充活动监视器百分比。

ϟ 31.5 W ▣ 22% ♨ 34.0 °C ▦ 64%

C · 只保留百分比

界面最紧凑、变化最连续，但容易让用户误以为它是 macOS 官方内存压力。即使重新计算，也无法保证与活动监视器完全同口径。
