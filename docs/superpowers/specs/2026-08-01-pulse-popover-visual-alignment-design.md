# Pulse 菜单栏与详情面板视觉对齐设计

日期：2026-08-01  
状态：用户已批准

## 1. 目标

在保留当前 `NSStatusItem + NSPopover` 架构和低内存特性的前提下，修复刷新控件焦点环、菜单栏视觉拥挤、图标比例失衡、行分割线不一致和面板颜色偏离 macOS 系统设置的问题。

## 2. 菜单栏

- 保留 2×2 指标及 `W`、`°C`、`%` 后缀，不缩写、不隐藏。
- 动态宽度继续取两列真实固有宽度，并在最右侧增加安全留白，避免内容紧贴状态项边界产生裁切感。
- 四个指标继续使用模板 SF Symbols，但恢复与原视觉语义一致的符号：功率用插头、电池温度用温度计、内存用芯片、CPU 用 CPU；统一图标的视觉尺寸与字重。
- 对横向较窄的插头符号使用单独的视觉尺寸补偿，不通过位图复制或新建图像缓存解决。

## 3. 详情面板结构

面板保留三个等宽圆角分组：

1. 六项指标组。
2. 刷新间隔与开机自动启动设置组。
3. “退出 Pulse”操作组。

三个分组采用相同的左右外边距、圆角和内容宽度。“退出 Pulse”显示为完整分组行，使整行都具有明确的可点击外观与点击区域。

## 4. 统一布局规则

- 所有行共享同一套布局常量：左侧内边距、图标槽宽、图标与标题间距、右侧内边距和分割线终点。
- 指标行与设置行的标题起点完全一致。
- 所有分割线从标题起点开始，到统一右侧内边距结束；最后一行不绘制分割线。
- 指标组允许较紧的行高，设置组和退出组允许系统设置式较高行高，但横向规则必须一致。
- 电源状态图标不再受窄符号比例影响而显得比其他图标明显更小。

## 5. 刷新间隔

- 继续使用真实 `NSPopUpButton`，保留键盘与辅助功能语义。
- 关闭其常驻蓝色焦点环；蓝框不是选中状态，也不作为当前值提示。
- 常态仅显示箭头圆形浅灰背景；悬浮时显示包含数值与箭头的完整浅灰圆角背景。
- 选择项继续限定为 1、2、3、5、10 秒，交互逻辑和持久化不变。

## 6. 系统动态颜色

- 面板外层改用 `windowBackgroundColor` 对应的系统窗口背景，不再使用会明显吸收墙纸色调的 popover 材质作为主底色。
- 三个分组使用系统动态浅灰控件背景；文字、次要文字、分割线均使用 AppKit 动态语义色。
- 浅色和深色外观均由系统动态色适配，不写死截图中的 RGB 数值。

## 7. 性能与维护约束

- 不新增计时器、系统查询、观察者或每次刷新创建的视图。
- 不恢复已删除的旧视图，不加入第三方 UI 框架。
- 图标仍复用模板图像；指标刷新仍只更新现有标签文本和颜色。
- 共享布局常量只保留一个来源，避免指标组与设置组再次各自漂移。

## 8. 测试与验收

- 测试刷新按钮无焦点环，同时仍是可操作的真实 `NSPopUpButton`。
- 测试三个分组宽度和水平起止一致。
- 测试指标行、设置行、退出行的图标与标题起点一致。
- 测试所有分割线具有相同起点和终点。
- 测试菜单栏长后缀内容所需宽度包含右侧安全留白，四项均不裁切。
- 生产视图渲染检查浅色外观、分组层级、退出行点击暗示、刷新常态与悬浮态。
- 完成后运行全部测试、warnings-as-errors 类型检查和正式构建，并复核稳定内存没有因纯布局修正明显增加。

## 9. 非目标

- 不改变六项指标的含义、数据源或刷新流程。
- 不新增标题、图表、设置项或状态栏第三行。
- 不追求对单张截图的硬编码像素复制；以 macOS 动态语义色和原生行为为准。
- 不自动提交 Git。
