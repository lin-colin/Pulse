# Pulse 电源状态与功耗表现矩阵设计文档 (Design Spec)

## 1. 背景与目标

在 Pulse macOS 系统监控菜单栏中，目前系统功耗的图标（`bolt.fill`）在“充电状态”与“高功耗警示”之间存在语义混淆。为了让用户在任何电源模式（充电、插电直供、电池放电）及不同负载情况下都能清晰、无歧义地了解系统状态，现设计并实施 **“方案 1 + 高负载表现矩阵”**。

## 2. 核心设计原则

- **图标与数字语义解耦**：
  - **图标 (Icon)**：主要负责表达 **电源物理连接模式**。
  - **数值 (Value, 如 `31.5 W`)**：专门负责表达 **系统功耗负载大小**。
- **状态准确与严格不可伪造**：
  - 严禁把不可用状态显示为 `0` 或掩盖缺失。
  - 严格保持与 `antigravity/skills/pulse-hardware-monitoring/SKILL.md` 中各项指标定义与 UI 规则 100% 一致。

## 3. 详细表现矩阵 (3 种电源模式 × 2 种负载状态)

| 电源物理模式 | 正常低功耗 (如 < 18W) | 高负载 / 剧烈功耗 (如 ≥ 18W 橙, ≥ 30W 红) | 设计逻辑与视觉体验 |
| :--- | :--- | :--- | :--- |
| **1. 电池放电模式**<br>*(未插电源，完全用电池)* | **图标**：`bolt.fill` (系统默认色)<br>**数值**：`6.8 W` (系统默认色) | **图标**：`bolt.fill` (**橙/红色**)<br>**数值**：`31.5 W` (**橙/红色**) | **电池正在剧烈掉电！**<br>图标与数值同时变橙/红，强力告警。 |
| **2. 插电直供模式**<br>*(插电但未充电池/100%/80%停充)* | **图标**：`powerplug.fill` (系统默认色)<br>**数值**：`11.5 W` (系统默认色) | **图标**：`powerplug.fill` (系统默认色)<br>**数值**：`42.0 W` (**橙/红色**) | **交流电供电正常，系统高负载！**<br>插头保持系统默认色（表示接口连通正常），**仅数值变橙/红**。 |
| **3. 正在充电模式**<br>*(适配器正在向电池充电)* | **图标**：`bolt.fill` (系统绿色)<br>**数值**：`15.2 W` (系统默认色) | **图标**：`bolt.fill` (系统绿色)<br>**数值**：`55.0 W` (**橙/红色**) | **正在正常充电，且系统高功耗！**<br>闪电保持绿色（表示充电一切正常），**仅数值变橙/红**（消除绿红冲突）。 |

## 4. 架构与组件变更规划

1. **`Pulse/UI/StatusItemView.swift`**：
   - 增加电源状态模型（能够区分 `isCharging` 与 `isPluggedIn`）。
   - 根据矩阵规则动态选择绘制图标（`bolt.fill` vs `powerplug.fill`）。
   - 解耦计算 `powerIconColor` 与 `powerTextColor`。
2. **`Pulse/UI/StatusBarController.swift`**：
   - 更新调用 `customView` 传递电源连接模式。
3. **`Pulse/Models/MetricCalculations.swift`**：
   - 扩充功耗染色和图标形态的纯函数与单元测试。
4. **`Tests/MetricCalculationsTests.swift`**：
   - 增加关于功耗图标与色彩矩阵解耦的自动化回归测试。

- 运行 warnings-as-errors swiftc typecheck。
- 运行 `./build.sh` 编译产物打包。
