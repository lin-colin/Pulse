# Pulse 下拉菜单极致 Mac 体验与视觉重构 Design Spec

## 1. 背景与目标

为了将 Pulse 下拉菜单从基础展示面板提升至 **顶级商业 macOS 软件（如 iStat Menus / AlDente / Stats）的极致视觉与交互水准**，解决目前在拥挤感、视觉层次、信息密度及交互直观性上的 5 大深层缺陷。

## 2. 5 大深度缺陷诊断

1. **缺陷 1：左右间距过度挤压（局促拥挤感）**
   - 第 3 行 `内存使用14.07 GB / 24.00 GB (59%)` 与第 6 行 `已连接电源 (未在充电)` 因菜单宽度过窄，导致左侧标题与右侧长文本紧紧撞在一起，失去了 Mac 原生的留白呼吸感。
2. **缺陷 2：6 行监控指标像“纯文本”，缺乏视觉层次**
   - 上半部分 6 项指标紧贴在一起，图标与文字全为暗色，缺乏“硬件看板 (Dashboard)”的层次与精细度。
3. **缺陷 3：内存与电源信息冗长**
   - 内存全量容量与百分比混在一起挤在同一行，信息密度失衡。
4. **缺陷 4：刷新间隔子菜单缺乏直观消耗提示**
   - 用户无法直观感知 1 秒与 5 秒刷新频次对 CPU 与电池寿命的影响。
5. **缺陷 5：开机自启缺乏“可点击/可切换”的直观交互暗示 (Affordance)**
   - `开机自动启动    已开启` 的字样样式与上方只读数据项目完全相同，用户一眼扫过去会误以为这只是一个只读状态展示，根本不知道**点击这一行即可直接切换开/关**。

---

## 3. 终极 Mac 体验重构方案

### 1. 面板宽度与留白舒张 (`260px` ➔ `310px`)
- 适度扩展下拉菜单面板宽度至 `310px`。
- 将右对齐制表符（`NSTextTab`）位置由 `190pt` 扩展至 `225pt`，给汉字标题与右侧数值留出约 **20px ~ 35px 苹果官方级的高级呼吸空间 (Breathing Room)**，彻底解决挤压撞字问题。

### 2. 内存与电源精细化文本
- 内存行精简为：`内存使用    14.07 GB (59%)`（中间增加标准半角空格，留白优雅，悬浮 Tooltip 显示总物理内存 24.00 GB）。
- 电源行精简为：`电源状态    已连接电源 (未在充电)`（因面板变宽 310px，全称展示极其优雅不拥挤）。

### 3. 开机自启增加明确的开关交互暗示 (解决缺陷 5)
- **方案**：采用开机自启开关状态暗示 `开关 Icon + 开机自动启动    已开启 ✓` (或右侧高亮开关系数/开关标记)。
- 当鼠标悬浮在开机自启这一行时，保持可点击的高亮反馈，让用户一目了然知道这是**可直接点击切换的配置开关**。

### 4. 刷新间隔增加直观建议提示
- 子菜单选项明示建议：
  - `1 秒 (高频)`
  - `2 秒`
  - `3 秒 (推荐)`
  - `5 秒`
  - `10 秒 (省电)`
